# Echo Dashboard

Echo Dashboard is a web dashboard for managing Echo bots.

## Current Features

- Echo account registration
- Username and password
- Password hashing
- Profile picture upload
- Login and logout
- Local account session
- Echo dashboard UI
- Discord-inspired design

## Planned Features

- Discord integration
- Echo bot connection
- Bot token setup
- Bot management
- Commands
- Automations
- Events
- Bot settings
- User settings

## Important

This first version uses browser `localStorage` for the account prototype.

A real online authentication system and secure backend will be added later.

Never put a Discord bot token directly inside frontend JavaScript.
